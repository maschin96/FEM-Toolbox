# v1.0.0 — Entwurf der Release Notes

**Nicht veröffentlicht.** Diese Notiz beschreibt den vorgesehenen stationären
M5-Umfang. Die endgültigen Release Notes entstehen erst nach bestandenem
[Release-Gate](../09_RELEASE_PROCESS.md); bis dahin ist v0.5.0 die aktuelle
Veröffentlichung.

Geplant ist eine stabile Forschungs-API für Wärme, lineare Elastizität,
Elektrostatik, `T → u`, `u ↔ φ` und `T → (u, φ)` über das versionierte
[TOML-Modell](../21_MODEL_SCHEMA.md). Der aktuelle Quellstand enthält dazu
Elektroden, den stationären Kombinationsmodus, Preflight und ein
Ergebnisbündel. Maßgeblich für zulässige Anwendungen, SI-Konventionen,
Elemente, Kopplungsrichtung, Genauigkeitsgrenzen und beobachtete
Ressourcengrößen ist die
[v1.0-Gültigkeitsübersicht](../26_VALIDITY_AND_LIMITS.md).

Die Verifikation umfasst synthetische Patch-, Bilanz-, Benchmark- und
Konvergenzfälle einschließlich des
[gekoppelten Mehrmaterialnachweises](../25_THERMOPIEZO_CONVERGENCE.md).
Eine experimentelle Validierung oder garantierte Skalierung auf große Modelle
ist nicht Teil der vorgesehenen Freigabe. Die konkrete Versionsnummer,
Prüfergebnisse und verbleibenden Risiken werden im Release-PR finalisiert.
